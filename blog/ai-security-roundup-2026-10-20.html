Framework Advisories

Security advisories for AI serving and agent frameworks, each sourced from the project's own GitHub Security Advisory.

  • vllm-project/vllm: GHSA-vvpg-rrww-wpmh: The OpenAI-compatible server's CORS middleware defaults allowed_origins to a wildcard, and the server performs no authentication unless --api-key/VLLM_API_KEY is set. A malicious web page can therefore use a victim's browser to reach an internal or localhost vLLM deployment, list models, and submit completions. CVSS v3.1 3.4 (Low); affects all versions with default config, fixed in >= 0.32.0.
  • vllm-project/vllm: GHSA-8397-8qf6-f2gm: The Phi-4 multimodal audio encoder runs its conformer attention in eager mode by default, materializing and retaining the full attention matrix for each of 24 layers. A single request with a max-length (~10 minute) audio clip can push memory use past what's available and OOM-crash the engine. CVSS v3.1 6.5 (Moderate); affects 0.31.0, fixed in >= 0.32.0.
  • vllm-project/vllm: GHSA-h3rc-j82p-2c3h: ImageMediaIO passes attacker-supplied image bytes to Pillow's format autodetection without restricting formats, so a file mislabeled as PNG can be handled by Pillow's EPS plugin, which shells out to the host's Ghostscript. On a build vulnerable to the unrelated CVE-2024-29510, that can lead to command execution; on Pillow 12.0.0-12.2.0 a malformed EPS can instead loop and exhaust workers (DoS only, no code execution). CVSS v3.1 8.1 (High); affects 0.30.0, fixed in >= 0.32.0.
  • vllm-project/vllm: GHSA-q97c-p368-75c4: An off-by-one in the tokenizer wrapper's max-token-id bound lets a pre-tokenized prompt token id equal to the vocab size pass input validation; with tensor-parallel size 1 the unmasked embedding lookup triggers a CUDA device-side assert that crashes the engine for all clients. CVSS v3.1 6.5 (Moderate); affects <= 0.30.0, fixed in >= 0.32.0.
  • vllm-project/vllm: GHSA-gq5q-89c7-vhvx: DeepSeek-OCR family models (DeepSeek-OCR, DeepSeek-OCR-2, Unlimited-OCR) return None from embed_multimodal when a legitimate image's normalized pixels sum to exactly zero (e.g. a half-black, half-white PNG), violating the method's contract and tripping a fatal sanity assert that shuts down the whole EngineCore and API server until manually restarted. CVSS v3.1 6.5 (Moderate); affects 0.30.0, fixed in >= 0.32.0.
  • vllm-project/vllm: GHSA-frvg-qw88-hww9 (CVE-2026-94624): OffloadingConnector with a P2P secondary tier keeps a ZeroMQ session alive for every never-established peer address an API client supplies via kv_transfer_params.prefill; around 340 such peers exhausted the default ZMQ socket quota in testing, and the next peer raised an uncaught error that crashed EngineCore and the API server. CVSS v3.1 6.5 (Moderate); affects 0.26.0, fixed in >= 0.32.0.
  • vllm-project/vllm: GHSA-542m-9234-8gvf: Chat templates render in a Jinja2 sandbox with no wall-clock timeout or output-size cap, inside a thread pool whose default single worker can't be interrupted — one malicious template can block all chat-style endpoints for every tenant, or OOM-kill the API-server process via string multiplication. CVSS v3.1 6.5 (Moderate); affects >= 0.19.0, fixed in >= 0.32.0.
  • vllm-project/vllm: GHSA-6757-hggm-hp2w: With --mm-processor-cache-type shm enabled, an authenticated caller can forge an SHM handle via features.kwargs_data and make the worker call pickle.loads() on attacker-staged bytes, with no need for VLLM_ALLOW_INSECURE_SERIALIZATION=1. The advisory body lists CVSS v3.1 8.8 (High, AC:L). Its structured metadata vector is AC:H, which scores 7.5 (High). As of Oct 25, 2026 the advisory had not been corrected; both scores are High. Affects <= 0.25.1, fixed in >= 0.32.0.
  • langchain-ai/langgraph: GHSA-8prr-f582-jqq3 (CVE-2026-115885): langgraph deploy --verbose printed the short-lived Docker registry push token used for docker login, exposing it to anyone who could read CI logs or terminal recordings for up to its 12-hour, repo-scoped lifetime. CVSS v4.0 4.1 (Moderate); affects langgraph-cli >= 0.4.15, <= 0.4.31, fixed in 0.4.32.
